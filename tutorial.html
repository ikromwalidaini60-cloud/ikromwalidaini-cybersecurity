🌐 Tutorial Membuat Website di GitHub

Ditulis dari pengalaman: Dari tidak tahu sama sekali → sampai berhasil membuat website yang bisa dilihat seluruh dunia!

💡 Pesan Penulis: "Saya menulis tutorial ini karena saya pernah merasakan kebingungannya. Saya dulu tidak tahu apa-apa, merasa sulit, dan hampir menyerah. Tapi ternyata kalau pelan-pelan dan sabar, SEMUA PASTI BISA!"

📖 BAB 1 — APA ITU GITHUB?

GitHub itu adalah tempat di internet yang menyediakan ruang gratis untuk menyimpan kode dan membuat website.

Ibaratnya seperti lemari penyimpanan di internet. Kita taruh semua file website di dalamnya, lalu GitHub akan memajangkannya supaya orang lain bisa melihatnya.

Siapa yang bisa pakai? Semua orang! Gratis! Tidak perlu bayar!

📖 BAB 2 — CARA DAFTAR AKUN GITHUB

Langkah 1: Buka alamat github.com di browser

Langkah 2: Klik tombol Sign up atau Daftar

Langkah 3: Isi alamat email, buat kata sandi, tulis nama pengguna kamu

Langkah 4: Ikuti petunjuk verifikasi sampai selesai

Langkah 5: Jika sudah masuk, kamu akan melihat halaman utama GitHub. Itu adalah "rumah" akunmu!

📖 BAB 3 — MEMBUAT TEMPAT PENYIMPANAN WEBSITE

Sebelum membuat halaman, kita harus membuat "kotak penyimpanan" dulu yang bernama Repository.

Langkah 1: Klik tombol New atau Create a new repository

Langkah 2: Isi nama tempatnya. Contoh: namaku-website

Langkah 3: Pilih Public — supaya bisa dilihat semua orang

Langkah 4: Centang kotak Add a README file

Langkah 5: Klik tombol Create repository

⚠️ Catatan Penting: Nama tidak boleh pakai spasi! Gunakan tanda hubung - sebagai pemisah.

📖 BAB 4 — MEMBUAT HALAMAN UTAMA

Website harus punya halaman utama yang bernama index.html. Ini adalah pintu masuk website kita.

Langkah 1: Klik tulisan Add file → pilih Create new file

Langkah 2: Di kolom nama file, tuliskan persis: index.html

Langkah 3: Di kolom besar di bawahnya, tuliskan kode HTML-nya

Langkah 4: Gulir ke bawah → klik tombol Commit new file

📖 BAB 5 — KODE HTML PALING DASAR

Ini adalah kode paling sederhana yang wajib ada di setiap halaman website:

<!DOCTYPE html>
<html>
<head>
<title>Judul Website Saya</title>
</head>
<body>
<h1>Halo! Selamat Datang!</h1>
<p>Ini website pertamaku!</p>
</body>
</html>

Penjelasan sederhananya:

  • <html> = Awal dari semua halaman
  • <head> = Bagian pengaturan halaman
  • <title> = Nama yang muncul di tab browser
  • <body> = Isi yang terlihat di halaman
  • <h1> = Tulisan judul besar
  • <p> = Tulisan paragraf biasa
⚠️ PENTING: Setiap tanda buka harus ada tanda tutupnya! Contoh: <html> harus ditutup dengan </html>. Kalau kurang satu tanda, websitemu bisa rusak!

📖 BAB 6 — MEMASANG GAMBAR DI WEBSITE

Langkah 1: Klik Add file → Upload files

Langkah 2: Pilih gambar dari HP/Komputer kamu

Langkah 3: Klik Commit changes → tunggu sampai selesai

Langkah 4: Di kode HTML, tambahkan baris ini:

<img src="nama-gambarmu.jpg" alt="Gambar Saya" style="width:100%;">
⚠️ SANGAT PENTING: Nama di dalam tanda kutip HARUS SAMA PERSIS dengan nama file yang diupload! Termasuk huruf besar/kecil dan akhiran (.jpg / .png)! Kalau beda sedikit saja, gambarnya TIDAK AKAN MUNCUL!

📖 BAB 7 — MEMBUAT ALAMAT WEBSITE

Supaya website bisa dibuka orang lain, kita harus mengaktifkan alamatnya dulu:

Langkah 1: Di halaman tempat penyimpananmu, klik tab Settings

Langkah 2: Cari bagian tulisan Pages di menu sebelah kiri

Langkah 3: Di bagian Source, pilih Deploy from a branch

Langkah 4: Di bagian Branch, ubah menjadi main → klik Save

Langkah 5: Tunggu beberapa menit ⏳ lalu kembali ke halaman Pages, nanti akan muncul alamat website seperti:

namamu.github.io/namanya

✅ Itu alamat websitemu! Bisa dibuka dari mana saja di seluruh dunia! 🌍

📖 BAB 8 — MASALAH YANG SERING TERJADI

❌ Gambar tidak muncul? → Cek nama di kode dan nama file di GitHub. HARUS SAMA PERSIS!

❌ Tampilan berantakan? → Cek tanda kurung dan tanda kutip, jangan ada yang kurang!

❌ Alamat belum muncul? → Tunggu 2-3 menit, kadang GitHub butuh waktu untuk memperbarui!

❌ Sudah diubah tapi belum berubah? → Tekan tombol segitiga di pojok kanan atas browser → pilih "Muat Ulang" atau tarik layar ke bawah!
